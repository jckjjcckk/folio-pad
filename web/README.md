# Folio web app

The React app that runs in Safari, on the web at `https://folio-app.jckjjcckk.com`, and inside the iPad app
(`ios/`, the Capacitor shell). Vite + React + TypeScript, Tailwind v4, OpenSheetMusicDisplay, Tone.js, supabase-js.

```bash
npm install
npm run dev          # LAN-exposed on :5173
npm test
```

Environment and the full setup: `../docs/setup.md`. iPad build: `../docs/ios.md`. Hosting: `../deploy/README.md`.
