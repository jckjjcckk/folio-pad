# Docs

- [setup.md](setup.md): run Folio on your own machine with your own Meta key.
- [submission.md](submission.md): the hackathon write-up: what Folio does, which Meta model does what, measurements, limits.
- [agent-loop.md](agent-loop.md): how Folio runs Muse Spark as an agent, with a commit tool whose checks the model cannot skip.
- [librarian-contract.md](librarian-contract.md): how the app and the librarian's handlers meet through the database.
- [ios.md](ios.md): the iPad app (Capacitor shell): build, sync, and how the web app behaves inside it.
- [features/](features/README.md): one file per feature with its status, Meta model, numbers and decisions.
- [acceptance/](acceptance/): the librarian pipeline run step by step, and the touch checklist for the iPad.
- [design/](design/): the design explorations that chose the app's direction, and the R3 design artboards.
- [fixtures/](fixtures/README.md): public-domain test scores, their licences, and Folio's result on each.

Elsewhere: `PRODUCT.md` and `DESIGN.md` (product and visual rules), `deploy/README.md` (hosting),
`api/experiments/README.md` (the measured experiments).
